# Retail Sales & Profit Dashboard
## Project Overview
An Advanced Excel dashboard project designed to analyze retail sales performance, customer profitability, and discount impact on business outcomes.
## Tools Used
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* XLOOKUP
## Key Performance Indicators (KPIs)
* Total Revenue
* Total Profit
* Profit Margin %
* Total Orders
* Average Order Value
## Analysis Performed
### Customer Profitability Analysis
Identified the top customers contributing to overall profitability.
### Discount Impact Analysis
Analyzed the relationship between discounts and profit margins across categories.
### Product Performance Analysis
Compared product-level sales and profitability.
## Dashboard Features
* Interactive Filters
* Dynamic Pivot Charts
* KPI Cards
* Business Insights Dashboard
